Enable @PRODUCT_NAME@

  1. Quit System Settings. Open Refresh Input Sources.command from this disk image to register the installed app and rebuild the input-source picker cache.
  2. Open System Settings → Keyboard → Text Input → Edit → +.
  3. Find @PRODUCT_NAME@ under Others, add it, and select it from the input menu.
  4. Open @PRODUCT_NAME@ Settings from its input menu and configure Ollama or an online model.

The refresh command backs up only the keyboard picker's generated cache. It does not change your enabled input sources, settings, or permissions. On a new Mac, a first installation may still need a logout/login before macOS discovers the input method.

Caps Lock off uses your first language; Caps Lock on uses your second language.

Optional selected-text translation needs permission in System Settings → Privacy & Security → Accessibility. Add ~/Library/Input Methods/@PRODUCT_NAME@.app if necessary. Updating an ad-hoc signed build may require renewing this permission.
