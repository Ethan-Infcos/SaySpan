Install @PRODUCT_NAME@

For Apple Silicon Macs running macOS 15 or later. Intel Macs are not supported.

@PRODUCT_NAME@ installs for your account in ~/Library/Input Methods/@PRODUCT_NAME@.app. The typing engines, dictionaries, and required libraries are included; Homebrew is not required.

After installation, quit System Settings and open Refresh Input Sources.command from this disk image. Then add @PRODUCT_NAME@ under Others in Keyboard → Text Input → Edit → +.

Before updating: finish or cancel any unfinished sentence, save your work, and switch to ABC. Installer may ask you to close @PRODUCT_NAME@. Your settings, saved credentials, and learned words are stored separately and remain in place.

Translation requires either a separately installed Ollama service and model, or an online API configured in @PRODUCT_NAME@ Settings. No model, API key, or personal data is included.

This is a test build with ad-hoc code signing. It has not been signed with Developer ID or notarized by Apple, so macOS may block a downloaded copy. Only approve a copy you trust through System Settings → Privacy & Security. Do not disable Gatekeeper.
